# Test_tg2

Игра на **Unity WebGL**, опубликованная через **GitHub Pages** и адаптированная
для запуска внутри **Telegram WebApp** (Mini App). Название сборки — `Test_tg2`,
версия `1.0.2`.

## Структура

```
.
├── index.html              Точка входа: стартовое меню, загрузка, пауза
├── app/                    Обвязка страницы, отделена от Unity-шаблона
│   ├── app.css             Вёрстка меню, кольцевой прогресс, баннеры
│   └── app.js              Состояния страницы, пауза, звуки, Telegram-мост
├── Build/                  Выход Unity WebGL (не редактируется вручную)
│   ├── game.loader.js
│   ├── game.framework.js
│   ├── game.data
│   └── game.wasm
├── TemplateData/           Иконки и изображения Unity-шаблона
└── .github/workflows/
    └── deploy.yml          Деплой статики на GitHub Pages
```

## Как запустить локально

Unity WebGL не работает по протоколу `file://` — нужен любой локальный
HTTP-сервер из корня репозитория:

```bash
# Python 3
python -m http.server 8080
# затем открыть http://localhost:8080

# или Node
npx serve .
```

## Как обновить сборку

1. В Unity: **File → Build Settings → WebGL → Build** в отдельную папку.
2. Скопировать содержимое папки `Build/` из экспорта в `Build/` этого репо
   (имена файлов должны совпадать с константой `BUILD` в `app/app.js`).
3. При необходимости обновить `productVersion`, `productName`, `companyName`
   в начале `app/app.js` — они же показываются на экране загрузки.

## Ориентация и полноэкранный режим

- **Телефон (Telegram / мобильный браузер)**: игра занимает весь экран в
  вертикальной (портретной) ориентации. Ориентация залочивается через Telegram
  SDK (`screenOrientation.lock("portrait-primary")`), в обычном мобильном
  браузере — через Fullscreen API + `screen.orientation.lock("portrait-primary")`
  при первом касании. Вырезы/чёлка и статус-бар учитываются через
  `safe-area-inset`: canvas вписывается в доступную область, не уходя под вырез.
- **ПК**: canvas растягивается на всё окно браузера (Unity сам синхронизирует
  разрешение рендера), ничего не центрируется фиксированными 960×600 и никуда
  не «съезжается» при ресайзе. Кнопка внизу по центру — toggle настоящего
  полноэкранного режима (повторное нажатие/Esc — выход).
- Если телефон держат горизонтально, показывается анимированная подсказка
  «Поверните телефон вертикально».

## Заставка и фон

- Штатный лоадер Unity-шаблона не используется: своя загрузка (см. выше) —
  сначала полупрозрачный слой с blur, сквозь который видно анимированный
  фон, а на старте движка он становится непрозрачным и держится ~2,5 с,
  поэтому движковый splash Unity не показывается. На постоянной основе его
  можно отключить в Unity: Player Settings → WebGL → Show Unity Splash Screen
  (требует лицензию Plus).
- Фон — процедурная анимация на canvas (градиентные «сияния» +
  дрейфующие мерцающие звёзды), генерируется кодом, ассеты не нужны.
  Анимация останавливается после старта игры и при сворачивании вкладки;
  уважается `prefers-reduced-motion`.

## Меню, счётчик и звук

- **Стартовое меню**: заставка с названием, слоганом и кнопкой «Играть».
  Скачивание 26 МБ начинается только по нажатию — трафик не тратится зря.
- **Экран загрузки**: кольцевой SVG-счётчик с процентом по центру и стадией
  («загрузка данных» → «запуск движка»); при сетевой ошибке — кнопка повтора.
- **Меню паузы**: «Продолжить» / «Заново» / переключатель звука. Открывается
  кнопкой ⏸ в правом верхнем углу, клавишами `Esc`/`P`, аппаратной «назад»
  в Telegram и автоматически при сворачивании вкладки.
- **Звуки** синтезируются на WebAudio без ассетов: взмах крыльев (шумовой
  свип + низкочастотное тело), удачное прохождение (восходящий двойной блип),
  смерть (пикирующая пила с шумовым крашем), клики меню. Мьют сохраняется в
  `localStorage`.
- Взмах играется сам: на `pointerdown` по canvas и на `Space`/`↑`/`W` — то
  есть попадает по тапам игры «тапни, чтобы взмахнуть».

### Как связать звук очка и смерти с кодом Unity

События «очко» и «смерть» знает только сама игра — из JS их перехватить
нельзя. Вызовите из C# в нужных местах мост `window.GameBridge`
(внешние вызовы доступны через `Application.ExternalEval`):

```csharp
// using UnityEngine;

// при наборе очка (прошли препятствие):
Application.ExternalEval("window.GameBridge && GameBridge.score()");

// при смерти:
Application.ExternalEval("window.GameBridge && GameBridge.death()");
```

Альтернативные имена для `ExternalCall`: `window.onPlayerScore()`,
`window.onPlayerDeath()`, `window.onPlayerFlap()`. Также доступны
`GameBridge.pause()`, `.resume()`, `.playSound("flap"|"score"|"death"|"ui")`,
`.setMuted(true|false)`.

## Настройка Telegram WebApp

Обвязка работает и в обычном браузере, и внутри Telegram:

- В `app/app.js` можно указать `TELEGRAM_BRIDGE_OBJECT` — имя GameObject в
  сцене Unity с методом `OnTelegramUser(string json)`, чтобы передать профиль
  пользователя после старта. По умолчанию `null` (не отправляется).
- Из C# доступны хелперы моста через `Application.ExternalCall`:
  `window.GameBridge.telegramUser()`, `.haptic("light")` (вибрация Telegram),
  `.closeApp()`, `.isTelegram()`.
- В интерфейсе Telegram включаются `expand()`, `disableVerticalSwipes()`,
  тёмная шапка/фон, лок вертикальной ориентации.

Чтобы опубликовать как Mini App: в [@BotFather] укажите Web App URL на
`https://<username>.github.io/test/`.

## Деплой

Push в `main` запускает workflow `deploy.yml`, который публикует репозиторий
как статический сайт на GitHub Pages. В настройках репо должен быть выбран
**Settings → Pages → Source: GitHub Actions**.
